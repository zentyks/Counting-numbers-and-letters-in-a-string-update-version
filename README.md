Подсчёт букв и цифр
📌 Описание проекта

Простая консольная программа на Python, которая считает количество букв и цифр в введённой строке.

🚀 Возможности
подсчёт букв в строке
подсчёт цифр в строке
игнорирование остальных символов
работа в бесконечном цикле
выход из программы по команде
💻 Как использовать
Введите любую строку
Программа покажет количество букв и цифр
Для выхода введите:
стоп
✍️ Примеры
Ввод:
hello123
Вывод:
Буквы: 5
Цифры: 3
Ввод:
abc 45!!
Вывод:
Буквы: 3
Цифры: 2
